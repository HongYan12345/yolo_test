# mxdzlk 图片资源爬虫使用说明

本项目第一步先获取训练素材：`monster` 怪物图片和 `item` 掉落物/物品图片。

当前已根据 mxdzlk 页面结构编写爬虫：

- 怪物列表：`https://mxdzlk.com/monster/?page_num=N`
- 怪物图片：`https://static.mapleartale.com/images/mob/{id}.png`
- 物品列表：
  - `https://mxdzlk.com/item/`
  - `https://mxdzlk.com/item/equip/`
  - `https://mxdzlk.com/item/?item_type=2`
  - `https://mxdzlk.com/item/?item_type=3`
  - `https://mxdzlk.com/item/?item_type=4`
  - `https://mxdzlk.com/item/?item_type=5`
- 物品图片：`https://static.mapleartale.com/images/item/{id}.png`

## 1. 爬虫脚本

```text
tools/crawl_mxdzlk_assets.py
```

只使用 Python 标准库，不需要额外安装依赖。

建议优先使用 Python 3.10 或 3.11 运行爬虫；如果电脑里已经安装 Python 3.12，也可以直接使用 Python 3.12。爬虫脚本只依赖标准库，3.12 没问题。这样后续数据合成、YOLO/PyTorch 训练、ONNX 推理也可以尽量共用同一个虚拟环境，避免维护多套环境。

注意：Python 3.12 用于训练/推理时，需要安装较新的 PyTorch、Ultralytics、ONNX Runtime 等依赖版本；如果后续遇到依赖安装问题，再回退到 Python 3.10/3.11。

## 1.1 推荐 Python 环境

Windows 下可先查看已安装的 Python 版本：

```bash
py -0p
```

优先推荐创建 Python 3.11 虚拟环境：

```bash
py -3.11 -m venv .venv
.venv\Scripts\python.exe -m pip install --upgrade pip
```

如果本机没有 Python 3.11，也可以使用 Python 3.10：

```bash
py -3.10 -m venv .venv
.venv\Scripts\python.exe -m pip install --upgrade pip
```

如果本机已经有 Python 3.12，也可以直接使用 Python 3.12：

```bash
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install --upgrade pip
```

后续执行爬虫时可以显式使用虚拟环境里的 Python：

```bash
.venv\Scripts\python.exe tools/crawl_mxdzlk_assets.py --kind monster --max-pages 1 --delay 1
```

如果当前 `.venv` 是 Python 3.14 创建的，建议改为使用 Python 3.10/3.11/3.12 重新创建 `.venv`，让爬虫、数据处理、训练和推理统一在同一环境下运行。

## 2. 输出目录

默认输出到：

```text
assets/
  monsters/
    raw/
      100100.png
      ...
    metadata.csv

  items/
    raw/
      2000000.png
      ...
    metadata.csv
```

`metadata.csv` 会记录：

```text
id,kind,name,item_type,source,page_url,image_url,file_path,status,http_status,content_type,size_bytes,sha256,error,downloaded_at,discovered_from
```

## 3. 先小规模测试

### 3.1 只测试怪物前 1 页

```bash
.venv\Scripts\python.exe tools/crawl_mxdzlk_assets.py --kind monster --max-pages 1 --delay 1
```

### 3.2 只测试物品前 1 页

```bash
.venv\Scripts\python.exe tools/crawl_mxdzlk_assets.py --kind item --max-pages 1 --delay 1
```

### 3.3 怪物和物品都测试前 1 页

```bash
.venv\Scripts\python.exe tools/crawl_mxdzlk_assets.py --kind all --max-pages 1 --delay 1
```

## 4. 正式爬取

### 4.1 爬取全部怪物

```bash
.venv\Scripts\python.exe tools/crawl_mxdzlk_assets.py --kind monster --max-pages 0 --delay 1
```

目前探测到 mxdzlk 怪物列表约 55 页，每页约 10 个资源。

### 4.2 爬取全部物品/掉落物素材

```bash
.venv\Scripts\python.exe tools/crawl_mxdzlk_assets.py --kind item --max-pages 0 --delay 1
```

目前探测到的物品来源包括：

- 普通 item 列表
- equip 装备列表
- item_type=2
- item_type=3
- item_type=4
- item_type=5

注意：物品页数较多，全部爬取会下载数千张图片，建议先小规模测试。

### 4.3 怪物和物品全部爬取

```bash
.venv\Scripts\python.exe tools/crawl_mxdzlk_assets.py --kind all --max-pages 0 --delay 1
```

## 5. 常用参数

### 5.1 只发现资源，不下载图片

```bash
.venv\Scripts\python.exe tools/crawl_mxdzlk_assets.py --kind monster --max-pages 1 --dry-run
```

### 5.2 限制每个来源最多下载数量

```bash
.venv\Scripts\python.exe tools/crawl_mxdzlk_assets.py --kind item --max-pages 0 --max-assets 100 --delay 1
```

说明：`--max-assets` 是每个列表来源的限制，不是全局限制。

### 5.3 重新下载已存在图片

```bash
.venv\Scripts\python.exe tools/crawl_mxdzlk_assets.py --kind monster --max-pages 1 --force
```

### 5.4 调整请求间隔

```bash
.venv\Scripts\python.exe tools/crawl_mxdzlk_assets.py --kind monster --max-pages 0 --delay 2
```

建议正式爬取时 `--delay` 不低于 1 秒，避免给网站造成压力。

### 5.5 指定 item 来源

```bash
.venv\Scripts\python.exe tools/crawl_mxdzlk_assets.py --kind item --item-sources equip,type2,type4 --max-pages 0 --delay 1
```

可选值：

```text
item,equip,type2,type3,type4,type5
```

## 6. 推荐执行顺序

第一步，确认 Python 版本并创建 Python 3.10/3.11/3.12 虚拟环境：

```bash
py -0p
py -3.11 -m venv .venv
.venv\Scripts\python.exe -m pip install --upgrade pip
```

如果没有 Python 3.11，则改用 Python 3.10：

```bash
py -3.10 -m venv .venv
.venv\Scripts\python.exe -m pip install --upgrade pip
```

如果电脑里已有 Python 3.12，也可以直接使用：

```bash
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install --upgrade pip
```

第二步，测试怪物：

```bash
.venv\Scripts\python.exe tools/crawl_mxdzlk_assets.py --kind monster --max-pages 1 --delay 1
```

第三步，测试物品：

```bash
.venv\Scripts\python.exe tools/crawl_mxdzlk_assets.py --kind item --max-pages 1 --delay 1
```

第四步，确认 `assets/monsters/raw/` 和 `assets/items/raw/` 中图片正常。

第五步，正式爬怪物：

```bash
.venv\Scripts\python.exe tools/crawl_mxdzlk_assets.py --kind monster --max-pages 0 --delay 1
```

第六步，正式爬物品：

```bash
.venv\Scripts\python.exe tools/crawl_mxdzlk_assets.py --kind item --max-pages 0 --delay 1
```

## 7. 训练前注意事项

这些图片还不是最终训练集，只是素材库。

后续还需要：

1. 采集真实地图背景截图。
2. 把怪物/物品 PNG 合成到真实或半真实背景上。
3. 自动生成 YOLO 标签。
4. 用少量真实截图做校准、验证和测试。

不能直接把透明 PNG 或物品图标原样作为最终实战训练集。
