# 冒险岛识图模型训练说明

本项目训练目标是一个四类 YOLO 目标检测模型：

```text
0: rope       # 绳索
1: platform   # 平台
2: monster    # 怪物
3: item       # 掉落物
```

注意：YOLO 类别编号必须从 `0` 开始。你口头说的“1.绳索 2.平台 3.怪物 4.掉落物”，落到 YOLO 标签文件里应写成 `0/1/2/3`。

模型输入为游戏截图或截图区域，输出绳索、平台、怪物和掉落物的边界框、类别和置信度。

## 0. GTX 1080 电脑上一键训练

本仓库已经准备了两套 Windows 一键训练入口：

```text
run_train_auto.cmd      # 通用入口：当前笔记本/其他电脑优先用这个
train_auto.ps1          # 通用入口的 PowerShell 主脚本

run_train_1080.cmd      # GTX 1080 专用入口
train_1080.ps1          # GTX 1080 专用 PowerShell 主脚本
```

### 0.1 当前笔记本/其他电脑推荐入口

如果不是固定使用 GTX 1080 那台电脑，推荐使用通用入口：

```powershell
git clone <你的仓库地址>
cd MapleStoryAI
.\run_train_auto.cmd
```

或者直接双击：

```text
run_train_auto.cmd
```

通用入口会自动检测当前电脑：

- 如果检测到 NVIDIA GPU，会优先使用 GPU 训练。
- 如果检测不到 NVIDIA GPU，会自动切到 CPU 流程。
- 如果是 GTX 10 系、老 Quadro/Tesla，会默认选择 CUDA 11.8 PyTorch wheel。
- 如果是较新的 NVIDIA 显卡且驱动满足要求，会优先选择 CUDA 12.1 PyTorch wheel。
- 如果显存低于约 7GB，默认 batch 会自动降到 4。
- 如果没有手动指定 `ImageSize`，GPU 默认用 640，CPU 默认用 512。

通用入口常用命令：

```powershell
# 自动检测电脑配置并训练
.\run_train_auto.cmd

# 当前电脑没有合适 GPU，强制 CPU 跑通流程
.\run_train_auto.cmd -Cpu

# 只检查环境和数据，不开始训练
.\run_train_auto.cmd -NoTrain

# 低显存电脑手动降低 batch
.\run_train_auto.cmd -Batch 4

# CPU 或低性能电脑降低图片尺寸
.\run_train_auto.cmd -Cpu -ImageSize 512 -Batch 4

# 重新生成合成数据和 YOLO 数据集
.\run_train_auto.cmd -RebuildSynthetic -RebuildYolo
```

### 0.2 GTX 1080 专用入口

在 GTX 1080 电脑上，也可以继续使用 1080 专用入口：

```powershell
git clone <你的仓库地址>
cd MapleStoryAI
.\run_train_1080.cmd
```

或者直接双击：

```text
run_train_1080.cmd
```

1080 专用入口默认使用 CUDA 11.8 PyTorch wheel，参数更偏向 GTX 1080。

这些入口会自动执行：

1. 创建 `.venv` 虚拟环境。
2. 优先使用 Python 3.11，其次 Python 3.10，再其次系统默认 Python。
3. 安装 CUDA 版 PyTorch。
4. 安装 `requirements-train.txt` 中的训练依赖。
5. 检查 `assets/monsters/raw/` 和 `assets/items/raw/` 是否存在素材。
6. 检查 `datasets/backgrounds/` 是否已有背景截图。
7. 检查 `datasets/real/images/` 是否已有真实截图。
8. 生成 `datasets/synthetic/` 合成训练集。
9. 生成 `datasets/yolo/data.yaml`。
10. 使用 YOLOv8n 开始训练。
11. 训练完成后导出 ONNX。

默认训练配置：

```text
model      = yolov8n.pt
imgsz      = 640
epochs     = 100
batch      = 8
workers    = 4
device     = 0
amp        = False
flipud     = 0
```

如果 GTX 1080 显存不够，可以运行：

```powershell
.\run_train_1080.cmd -Batch 4
```

如果只想检查环境和数据集，不想立刻训练：

```powershell
.\run_train_1080.cmd -NoTrain
```

如果要重新生成合成数据和 YOLO 数据集：

```powershell
.\run_train_1080.cmd -RebuildSynthetic -RebuildYolo
```

如果 CUDA 环境暂时装不好，可以 CPU 兜底测试流程：

```powershell
.\run_train_1080.cmd -Cpu -Batch 4 -ImageSize 512
```

注意：即使一键脚本已经准备好，训练前仍然必须有以下人工数据：

```text
datasets/backgrounds/      # 空地图/少目标背景截图，不需要标注
datasets/real/images/      # 真实游戏截图，需要人工标注
datasets/real/labels/      # 真实截图 YOLO 标签
```

标注结论：

- `assets/monsters/raw/`、`assets/items/raw/`：爬虫素材，不需要你手工标注。
- `datasets/backgrounds/`：背景截图，不需要标注。
- `datasets/synthetic/`：合成图由脚本自动生成 `monster/item` 标签，即 `2/3`，不自动生成 `rope/platform`。
- `datasets/real/images/`：真实游戏截图必须人工标注。
- 如果真实截图里有绳索、平台、怪物或掉落物，必须在对应 `.txt` 里写 YOLO 框。
- 如果真实截图里没有这四类目标，也必须放一个同名空 `.txt`，表示负样本。
- 如果真实截图缺少对应 `.txt`，脚本会停止，避免把“没标注的有目标图片”误当成“无目标负样本”。

如果这些目录为空，或者真实截图缺少对应标签文件，脚本会停止并提示需要补充数据。

## 3. 第一步：准备背景截图

先进入游戏，截取一批固定分辨率的地图背景图。

放入：

```text
datasets/backgrounds/
```

建议：

- MVP 起步：50~200 张。
- 尽量覆盖 3~5 张准备挂机的地图。
- 尽量使用空地图、少怪地图、少技能特效截图。
- 截图区域应和后续推理区域一致，例如 800×600 或固定战斗 ROI。
- 背景里可以有 UI，但建议后续尽量裁掉聊天框、背包、任务栏等无关 UI。

---

## 4. 第二步：生成合成训练图

使用脚本：

```text
tools/make_synthetic_dataset.py
```

示例命令：

```powershell
python tools/make_synthetic_dataset.py `
  --background-dir datasets/backgrounds `
  --monster-dir assets/monsters/raw `
  --item-dir assets/items/raw `
  --output-dir datasets/synthetic `
  --count 3000 `
  --seed 42
```

如果使用 cmd.exe，把反引号换成 `^`：

```cmd
python tools\make_synthetic_dataset.py ^
  --background-dir datasets\backgrounds ^
  --monster-dir assets\monsters\raw ^
  --item-dir assets\items\raw ^
  --output-dir datasets\synthetic ^
  --count 3000 ^
  --seed 42
```

输出：

```text
datasets/synthetic/images/*.jpg
datasets/synthetic/labels/*.txt
```

注意：合成图只会自动生成 `monster/item` 标签，类别编号分别是 `2/3`；不会自动生成 `rope/platform` 标签。

如果你之前已经生成过旧版两类合成数据，必须重新生成：

```powershell
.\run_train_auto.cmd -RebuildSynthetic -RebuildYolo
```

或者 GTX 1080 专用入口：

```powershell
.\run_train_1080.cmd -RebuildSynthetic -RebuildYolo
```

YOLO 标签格式：

```text
class_id x_center y_center width height
```

全部坐标均为 0~1 归一化。

## 5. 第三步：准备真实截图和人工标注

真实截图放入：

```text
datasets/real/images/
```

对应标签放入：

```text
datasets/real/labels/
```

示例：

```text
datasets/real/images/frame_000001.png
datasets/real/labels/frame_000001.txt
```

如果一张图没有绳索、平台、怪物、掉落物这四类目标，也必须放一个空的 `.txt` 标签文件，作为负样本。不要省略这个 `.txt`，因为省略标签文件和“确认无目标”不是一回事。

推荐标注工具：

- CVAT
- Label Studio
- LabelImg
- Roboflow

标注规则：

- 绳索标为 `0 rope`
- 平台标为 `1 platform`
- 怪物标为 `2 monster`
- 掉落物标为 `3 item`
- 角色、宠物、NPC、技能特效、背景装饰不标注
- 严重遮挡且无法判断的目标可以不标
- 小目标 item 如果希望模型能拾取，就必须标注并保留足够样本
- 每张真实截图都必须有同名 `.txt` 标签文件
- 没有任何目标的真实截图使用空 `.txt`，作为负样本
- 不要把未标注的有目标截图当负样本，否则会显著拉低识别效果

补充说明：

- `monster/item` 可以通过合成图自动生成一部分标签，但真实截图里仍然建议补标。
- `rope/platform` 目前主要依赖真实截图人工标注。
- 平台和绳索是导航目标，如果后续需要非常精确的站位/路径，YOLO 框可以先做 MVP；更精确时再考虑分割模型或额外地图结构解析。

MVP 起步建议：

```text
真实截图：100~500 张
含绳索：不少于 50~150 张
含平台：不少于 100~300 张
含怪物：不少于 100~300 张
含掉落物：不少于 100~300 张
负样本：不少于 50~100 张
```

更稳定的第一版建议：

```text
真实截图：500~1000 张
合成图：3000~10000 张
```

## 6. 第四步：构建 YOLO 数据集

使用脚本：

```text
tools/build_yolo_dataset.py
```

示例命令：

```powershell
python tools/build_yolo_dataset.py `
  --synthetic-dir datasets/synthetic `
  --real-dir datasets/real `
  --output-dir datasets/yolo `
  --clean `
  --seed 42
```

输出：

```text
datasets/yolo/
  images/train/
  images/val/
  images/test/
  labels/train/
  labels/val/
  labels/test/
  data.yaml
```

默认策略：

- 合成图只进入 train。
- 真实截图按 70/20/10 划分为 train/val/test。
- 真实截图缺少对应标签文件时默认报错。
- 真正没有目标的负样本需要手动创建同名空 `.txt`。
- 输出的 `data.yaml` 使用四类：`0 rope`、`1 platform`、`2 monster`、`3 item`。
- 验证集和测试集不会使用合成图，避免指标虚高。

如果之前已经生成过旧版 `datasets/yolo/data.yaml`，需要重建：

```powershell
.\run_train_auto.cmd -RebuildYolo
```

如果想限制合成图数量：

```powershell
python tools/build_yolo_dataset.py `
  --synthetic-dir datasets/synthetic `
  --real-dir datasets/real `
  --output-dir datasets/yolo `
  --synthetic-train-limit 3000 `
  --clean `
  --seed 42
```

## 7. 第五步：安装训练环境

建议使用 Python 3.10 或 3.11。

创建虚拟环境：

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
```

如果要用 NVIDIA GPU，例如 GTX 1080，建议先安装 CUDA 版 PyTorch。GTX 1080 是 Pascal 架构，默认推荐 CUDA 11.8 wheel，对旧驱动兼容性通常更稳：

```powershell
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118
```

`train_1080.ps1` 默认也会使用 `cu118`。如果你的 1080 电脑 NVIDIA 驱动较新，想改用 CUDA 12.1 wheel，也可以运行：

```powershell
.\run_train_1080.cmd -TorchCudaIndexUrl https://download.pytorch.org/whl/cu121
```

然后安装项目训练依赖：

```powershell
pip install -r requirements-train.txt
```

检查 GPU：

```powershell
python -c "import torch; print(torch.__version__); print(torch.cuda.is_available()); print(torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'CPU')"
```

如果输出包含：

```text
True
NVIDIA GeForce GTX 1080
```

说明可以使用 GPU 训练。

## 8. 第六步：开始训练

确认存在：

```text
datasets/yolo/data.yaml
```

GTX 1080 推荐起步命令：

```powershell
yolo detect train model=yolov8n.pt data=datasets/yolo/data.yaml imgsz=640 epochs=100 patience=20 batch=8 device=0 workers=4 amp=False flipud=0
```

如果显存不足：

```powershell
yolo detect train model=yolov8n.pt data=datasets/yolo/data.yaml imgsz=640 epochs=100 patience=20 batch=4 device=0 workers=4 amp=False flipud=0
```

如果还是显存不足，再降输入尺寸：

```powershell
yolo detect train model=yolov8n.pt data=datasets/yolo/data.yaml imgsz=512 epochs=100 patience=20 batch=8 device=0 workers=4 amp=False flipud=0
```

CPU 训练命令：

```powershell
yolo detect train model=yolov8n.pt data=datasets/yolo/data.yaml imgsz=512 epochs=80 patience=15 batch=4 device=cpu workers=2 flipud=0
```

说明：

- 第一版建议先用 `yolov8n.pt` 跑通闭环。
- item 是小目标，优先保留 `imgsz=640`。
- 如果 item 漏检严重，优先增加真实 item 标注和改进合成质量。
- 不建议第一版直接上 medium/large 模型。

## 12. 常见问题

### 12.1 没有背景图时能不能训练？

不建议。没有背景图只能使用透明素材原图，域差异太大，实战效果会很差。

### 12.2 可以只用合成图训练吗？

可以用于冷启动，但不能作为最终验收。最终必须用真实截图验证和微调。

### 12.3 item 检测差怎么办？

优先处理：

1. 增加真实地面掉落物截图。
2. 增加 item 合成数量。
3. 调整合成尺寸，让 item 更接近真实游戏内大小。
4. 保持 `imgsz=640`。
5. 加入角色附近 ROI 二次检测。

### 12.4 训练指标很高但实战差怎么办？

通常是验证集不真实或合成域差异太大。

解决：

1. val/test 改为真实截图。
2. 增加负样本。
3. 收集误检帧补标。
4. 降低不真实合成比例。
5. 加入实战录屏抽帧做主动学习。

### 12.5 标签文件可以为空吗？

可以，但只适用于真实无目标截图。空标签表示该图没有 rope/platform/monster/item 四类目标，是负样本。

如果图片里有绳索、平台、怪物或掉落物，就不能用空标签，必须画框标注。

### 12.6 我到底哪些图片要标注？

需要人工标注的只有：

```text
datasets/real/images/
```

不需要人工标注的有：

```text
assets/monsters/raw/       # 爬虫怪物素材
assets/items/raw/          # 爬虫物品素材
datasets/backgrounds/      # 背景截图
datasets/synthetic/        # 合成图，monster/item 标签自动生成
```

真实截图标注输出放到：

```text
datasets/real/labels/
```

示例：

```text
datasets/real/images/frame_000001.png
datasets/real/labels/frame_000001.txt
```

如果 `frame_000001.png` 里有绳索/平台/怪物/掉落物，`frame_000001.txt` 必须写框。
如果 `frame_000001.png` 是无四类目标截图，`frame_000001.txt` 可以是空文件。
